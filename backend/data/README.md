# Data Directory

Please manually download and add the dataset here.
All the PDFs need to be in a directory named `pdfs` here, e.g.

```
pdfs/
  abc.pdf
  def.pdf
  ...
  xyz.pdf
```

The `pdfs` directory is automatically excluded from any commits via the `.gitignore`.
